Logical Model: Patienten-Stammdaten

Official URL: https://gabriel0316.github.io/ig-tooling-pages/ig/ig-tooling/StructureDefinition/PatientHI Version: 0.5.2
Draft as of 2025-10-08 Computable Name: PatientHI

Patient/Teilnehmer basierend dem Entwurf der Datenspezifikation des modularen Rahmenkonzepts für Österreich für das Disease-Management bei chronischer Herzinsuffizienz.

Usages:

  • Use this Logical Model: Medizinische Datensätze - Erstdokumentation (im Rahmen der Erstabklärung erhoben/durchgeführt) and Medizinische Datensätze - Folgedokumentation
